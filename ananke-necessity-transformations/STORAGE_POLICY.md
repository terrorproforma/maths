# Repository-First Storage Policy

This GitHub directory is the canonical project store.

- Research notes, source code, tests, machine-readable results, figures, and release artifacts are committed here.
- Git commits are the authoritative record of project progression.
- Ephemeral execution environments are staging and verification surfaces only.
- A result is not treated as preserved until its source and relevant outputs are committed.
- Superseded results remain in Git history and are corrected through explicit changelog or errata entries rather than silent deletion.
