## Hard consistency results

Using left-handed Weyl fields, the code verifies exactly:

\[
\mathcal A_{SU(3)^2Y}=0,\quad \mathcal A_{SU(2)^2Y}=0,\quad
\mathcal A_{Y^3}=0,\quad \mathcal A_{\mathrm{grav}^2Y}=0,\quad
\mathcal A_{SU(3)^3}=0.
\]

There are four SU(2) doublets per generation after colour multiplicity, so the Witten parity is even.

### What the framework refuses to do

1. Call UV incompleteness a low-energy contradiction.
2. Call every fitted parameter an anomaly.
3. Call a naturalness preference an empirical fact.
4. Treat a current precision tension as timeless.
5. Average a ghost or anomaly failure against a good cosmological fit.
6. Reward novelty independently of correctness.

## Strongest result and failure modes

The strongest result is the operational ledger itself. It can falsify a proposed successor early. It does not solve the seams. A candidate fails if it lacks a complete theory tuple, has an anomalous gauge symmetry, propagates a ghost, lacks a well-posed initial-value problem, or cannot recover the established low-energy domains.
