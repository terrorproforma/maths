# TP-15 — Shear-to-tilt

**Author:** Angus Muffatti  
**Status:** QUEUED

## Goal

Define shear and tilt covariantly, then determine whether a dynamical, foliation-independent conversion between them exists and can produce a genuine observable rather than a coordinate or slicing effect.

## Kinematic starting point

\[
\nabla_\mu u_\nu
=
\frac13\theta h_{\mu\nu}
+\sigma_{\mu\nu}
+\omega_{\mu\nu}
-u_\mu a_\nu.
\]

“Tilt” must be defined invariantly, for example by the relation between a matter/energy-frame timelike vector and a geometrically selected foliation normal.

## Required outputs

- covariant shear variable and tilt observable;
- action and conversion field/mechanism;
- conserved quantities and constraint propagation;
- separation from frame dragging, shift-vector choice, torsion, and foliation gauge;
- exact solution and energy budget;
- perturbative and cosmological consequences.
