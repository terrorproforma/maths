# TP-05 — Neutral-to-charged state conversion

**Author:** Angus Muffatti  
**Status:** QUEUED

## Goal

Establish the Standard Model ceiling for converting a weakly interacting neutral state into a charged state after propagation, then test the smallest unitary extension capable of materially enhancing the conversion.

## Required outputs

- Standard Model charged-current baseline;
- coherent, resonant, and matter-enhanced conversion analysis;
- charge, energy, and momentum accounting;
- attenuation, decoherence, and detector requirements;
- classification of viable new mediators;
- no-go bound or explicit model with a measurable conversion probability.

## Early fatal gates

Gauge invariance, anomaly cancellation, positive physical spectrum, causal propagation, and electric-charge conservation precede phenomenology.
