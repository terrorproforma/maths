# Scientific and execution risk register

| Risk | Consequence | Detection | Mitigation |
|---|---|---|---|
| Exact source/input artifacts unavailable | X-track cannot exceed documentary/reconstructed tier | unresolved ledger items | pursue author archive; preserve E-track distinction |
| MRI under-resolution | incorrect magnetic saturation and jet timing | quality-factor distributions, resolution sequence | finer grid/local refinement; do not infer convergence from morphology |
| Atmosphere/floor-dominated funnel | artificial baryon loading or luminosity | injected mass/energy budgets and floor occupancy | lower floors with stability study; report systematic envelope |
| Neutrino microphysics mismatch | wrong cooling, Ye and disk wind | source-term unit tests and luminosity comparison | freeze exact tables/interpolation; cross-code microphysics test |
| Cowling switch mismatch | divergent late-time disk/jet evolution | checkpoint and metric-change audit | reproduce trigger exactly; matched control without switch |
| Chaotic/turbulent divergence | pointwise mismatch despite physical equivalence | ensembles and statistical metrics | compare distributions, spectra and integrated budgets |
| Boundary contamination | spurious ejecta/field reflections | causal/boundary diagnostics | enlarge domain; absorbing/radiative boundary verification |
| I/O dominates or corrupts run | lost allocation and incomplete lineage | throughput pilots, checksum failures | tiered outputs, asynchronous I/O, checkpoint promotion |
| Rank-topology sensitivity | nondeterministic drift | decomposition/restart tests | record topology; define reproducibility envelope |
| Visual transfer-function tuning | false appearance of agreement | physical gates fail while movie looks similar | render only after diagnostic validation |
