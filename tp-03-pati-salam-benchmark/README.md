# TP-03 — Complete Pati–Salam benchmark

**Author:** Angus Muffatti  
**Status:** QUEUED  
**Dependency:** TP-00 frozen acceptance framework; independent of TP-02 completion.

## Goal

Construct a complete, anomaly-free, symmetry-broken Pati–Salam model based on

\[
SU(4)_C\times SU(2)_L\times SU(2)_R,
\]

including the scalar sector, vacuum, fermion masses and mixing, neutrino masses, gauge-coupling running, baryon/lepton violation, cosmological defects, and at least one discriminating observable.

## First kill tests

- local and global anomaly cancellation;
- correct chiral Standard Model recovery;
- stable symmetry-breaking vacuum;
- proton/nuclear stability;
- flavour and leptoquark constraints;
- viable neutrino sector.

## Required terminal outcome

A reproducible viable benchmark, or a precise no-go/obstruction for the declared minimal model class. TP-00 gates are scored independently; no aggregate score is permitted.
