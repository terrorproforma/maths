# Chronometric Emergence

**Author: Angus Muffatti**

This directory holds the **original work** of the chronometric-emergence research programme.

- [`original-info/`](original-info/) — the original research packages, one folder per iteration from v0.1 (`chronometry_research_package_v0.1/`) through v1.9 (`chronometric_3pi_prehpc_v1_9/`), plus the loose original files (crossed-null paper source and PDF, v0.2 audit files, v1.8 pre-HPC spec, checklist and PDF, and verification scripts).
- [`sources/`](sources/) — the original project conversation snapshot (`Photon_Perspective_in_Relativity.txt`).

An earlier attempted reconstruction of the response-by-response archive (with regenerated artifacts) previously lived in this directory; it was removed in favour of the recovered originals and remains available in git history if ever needed.
