\[
\boxed{

The second relation is independent of the scalar amplitude, its coupling strength, and the source charge. It is the first genuinely nonzero, dimensionless clock–equivalence-principle consistency prediction in this programme.

## 2. All-orders microscopic scale-invariant QCD

### 2.1 Field-dependent subtraction standard

Work in

\[
d=4-2\epsilon.
\]

Replace the ordinary external dimensional-regularisation scale by

\[
\boxed{
\mu_\chi=z\,\chi^{1/(1-\epsilon)},
}
\]

where \(z\) is dimensionless. Bare couplings are written as

\[
g_{s,0}=\mu_\chi^\epsilon Z_g g_s,
\]

with corresponding powers of \(\mu_\chi\) multiplying Yukawa and scalar couplings.

The resulting bare action contains only dimensionless parameters and transforms homogeneously under dilatations. Renormalisation generates every symmetry-compatible higher-dimensional operator. The correct object is therefore an **all-orders Wilsonian effective field theory**, not a finite-coupling power-counting-renormalisable model.

### 2.2 Exact Ward identity

Let \(\Gamma\) denote the renormalised 1PI functional including the required Wilsonian operator tower. Exact scale invariance gives a functional identity of the schematic form

\[
\mathcal D\Gamma=0,
\]

where \(\mathcal D\) acts simultaneously on coordinates and on all fields according to their engineering dimensions. Ordinary running with respect to the dimensionless parameter \(z\) survives; the point is that no independent dimensionful subtraction standard remains.

For a vacuum

\[
\langle\chi\rangle=f\neq0,
\]

any physical pole mass or spectral gap must have the homogeneous form

\[
\boxed{
M_A=f\,\mathcal F_A(g_i,z,c_k,\ldots).
}
\]

For QCD with \(n_f\) active coloured flavours,

\[
\boxed{
\Lambda_{n_f}=c_{n_f}\chi
}
\]

in the homogeneous adiabatic limit. The first allowed corrections are derivative operators rather than arbitrary local functions of \(\chi\).

### 2.3 Precise limitation

This construction is stronger than merely choosing \(\mu\propto\chi\), because the co-scaling is encoded in the bare functional and its Ward identity. It is nevertheless not yet:

- a finite-parameter perturbatively renormalisable UV completion;
- a constructive proof of nonperturbative QCD plus \(\chi\);
- a proof of quantum gravity;
- a solution to the hierarchy or cosmological-constant problems.

## 3. Exact all-orders threshold recursion

Let \(\Lambda_n\) be the RGI scale of a theory with \(n\) active coloured fermions, and let \(\widehat m_j\) be the RGI mass of a heavy threshold that is integrated out. Dimensional analysis of physical RGI quantities implies

\[
\boxed{
\Lambda_{n-1}
=
\widehat m_j\,
\mathcal F_j\!\left(\frac{\Lambda_n}{\widehat m_j}\right).
}
\]

Define the exact response

\[
A_j
=
\frac{\partial\ln\mathcal F_j}
{\partial\ln(\Lambda_n/\widehat m_j)}.
\]

Differentiation gives

\[
\mathrm d\ln\Lambda_{n-1}
=
A_j\,\mathrm d\ln\Lambda_n
+(1-A_j)\,\mathrm d\ln\widehat m_j.
\]

Now define the lock defects

\[
\delta_n
=
\mathrm d\ln\frac{\Lambda_n}{\chi},
\qquad
\epsilon_j
=
\mathrm d\ln\frac{\widehat m_j}{\chi}.
\]

Then

\[
\boxed{
\delta_{n-1}
=A_j\delta_n+(1-A_j)\epsilon_j.
}
\]

This equation is exact. Scheme and loop dependence are contained only in the physical response \(A_j\).

For multiple thresholds,

\[
\boxed{
\delta_3
=
\left(\prod_{n=4}^{N}A_n\right)\delta_N
+
\sum_{n=4}^{N}
(1-A_n)
\left(\prod_{k=4}^{n-1}A_k\right)
\epsilon_n.
}
\]

Immediate consequences:

1. If \(\delta_N=0\) and every \(\epsilon_n=0\), then \(\delta_3=0\) to all orders.
2. A single misaligned threshold produces a calculable low-energy defect.
3. Threshold responses compose linearly in the infinitesimal lock defects.
4. The one-loop coefficient is only the first approximation to an exact decoupling response.

The coefficient \(2/27\) is established QCD threshold physics. Its role here is new only in the restricted sense that it becomes the transfer coefficient from a microscopic scale-lock defect to chronometric shear.

An observable equivalence-principle signal requires the ratio mode to be extremely light. Its range is approximately

\[
\lambda_C=\frac{\hbar}{m_ac}.
\]

Representative requirements are

\[
m_a\lesssim3.1\times10^{-14}\ {\rm eV}
\]

for Earth-scale range and

\[
m_a\lesssim1.3\times10^{-18}\ {\rm eV}

for Sun–Earth range.

The heavy coloured fermion generates a Coleman–Weinberg contribution

\[
\Delta V_\Psi
=
-
\frac{N_c}{16\pi^2}

\left[
\ln\frac{M_\Psi(\theta)^2}{\mu^2}-\frac32

For \(M_\Psi\sim f_a\sim M_{\rm P}\), a Sun-range scalar requires roughly

\[

That is technically possible as a tiny spurion, but phenomenologically sterile without an additional mechanism. A naturally observable long-range realization likely requires one of:

- collective symmetry breaking;
- supersymmetric cancellation;
- sequestering;
- clockwork or alignment;
- a composite near-marginal modulus;
- a threshold whose mass is parametrically below the universal scale but cosmologically safe.

This is now the principal model-building bottleneck.
