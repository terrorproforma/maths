# Package manifest

- `config/`: production and portable solver specifications.
- `src/chronometric_hpc/`: kernel loader, vertex helpers, BSE helper and preflight driver.
- `tests/`: regression tests.
- `inputs/`: v1.6-v1.8 control arrays and numerical results.
- `docs/`: equations, launch checklist and literature manifest.
- `preflight.sh`: one-command regression run.

The package is a preflight and initialization layer. It is not the production non-Abelian 3PI solver.
