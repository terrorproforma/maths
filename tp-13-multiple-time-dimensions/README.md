# TP-13 — Multiple operational time dimensions

**Author:** Angus Muffatti  
**Status:** QUEUED

## Goal

Classify literal and relational multi-time systems and derive the minimum conditions under which one causal, unitary, observable time remains.

## Separate branches

1. literal spacetime signature with more than one timelike direction;
2. multiple relational clock parameters on one Lorentzian spacetime;
3. a constrained phase space with one emergent physical time.

## Early kill tests

- ultrahyperbolic initial-value problem;
- negative-energy and negative-norm modes;
- causal-order ambiguity and closed causal structures;
- probability interpretation;
- recovery of one ordinary Lorentzian clock sector.

## Terminal outcome

A no-go or classification theorem, or an explicit constrained model whose physical observables are causal and unitary.
